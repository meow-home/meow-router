# Changelog — Meow Gateway v0.3.0 → v0.4.0

## 🚀 New Features

### In-app update check & download
- Add a **Check update** button in the sidebar footer that reads the latest
  GitHub release and compares it against the current app version.
- Show an update modal when a newer version is available, with a
  **Download & Install** button and live download progress.
- Download the platform installer (Windows `.exe`, macOS `.dmg`, Linux
  `.AppImage`/`.deb`), verify its SHA-256 digest when one is exposed, and open
  it for the user to run.
- Emit an OS notification when a background download completes, and re-open the
  app window when the notification is clicked.
- Check for updates automatically on launch, without interrupting the user.

## 🐛 Bug Fixes
- Fix a second copy of the app being launched when the icon is double-clicked
  while it is already running. The app now enforces a single instance, so only
  one window, one tray icon and one gateway start, and the existing window is
  re-focused instead.
