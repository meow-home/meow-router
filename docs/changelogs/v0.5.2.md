# Changelog — Meow Gateway v0.5.1 → v0.5.2

## 🐛 Bug Fixes
- Anthropic Messages API: serialize non-streaming tool calls so Claude Code can
  parse them. Previously the OpenAI-compatible adapter dropped
  `message.tool_calls` on the non-streaming path, so a tool call came back with
  empty `content` and `stop_reason: "tool_use"`, which made Claude Code fail
  with "The model's tool call could not be parsed (retry also failed)".

## 🧹 Internal & Docs
- Bump workspace packages and gateway default version to 0.5.2.
