# Changelog — Meow Gateway v0.8.1 → v0.9.0

## 🚀 New Features

### Modern UI Redesign with Meow-Coding Design System
- Redesigned navigation sidebar with theme toggling (light/dark mode) and Lucide icons.
- Redesigned Gateway Control Center view with status overview, model/route metrics, and quick action cards.
- Redesigned Providers screen with provider cards grid, custom brand avatars, quota status bars, and modal UX.
- Redesigned Models and Virtual Models views with control bar search, capability badges, routing policy configuration, and streamlined modal forms.
- Redesigned Dashboard view with real-time stats cards and enhanced metrics.

## 🐛 Bug Fixes
- UI: Fixed model creation & edit modal layout and styling consistency across light and dark themes.
- CSS: Cleaned up trailing/duplicate syntax in `meow.css` and removed universal border-radius rule from root selector.

## 🧹 Internal & Docs
- Added reusable UI component primitives (`BaseModal`, `BaseDropdown`, `BaseSelect`, `BaseInput`).
- Added theme tokens and design specs for meow-coding style.
- Updated docs, specs, and implementation plans.
- Bumped workspace packages and gateway version to v0.9.0.
