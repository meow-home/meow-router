# Changelog — Meow Gateway v0.9.1 → v0.9.2

## 🐛 Bug Fixes
- Antigravity adapter: Fixed Claude model requests failing with 400 "JSON schema is invalid. It must match JSON Schema draft 2020-12" when tools contained `anyOf` unions (e.g. `monitor.until_exit: anyOf(boolean, number)`). The Cloud Code Assist backend forwards tool `input_schema` to Anthropic, whose validator does not accept `anyOf`; the adapter now flattens `anyOf` to the first non-null branch for Claude models.
- Antigravity adapter: Dropped `nullable` from tool schemas for Claude models instead of converting it to an `anyOf` null union, which was also rejected by Anthropic's strict validator.

## 🧹 Internal & Docs
- Bumped workspace packages and gateway default version to v0.9.2.
- Added regression test for `anyOf` flattening on Claude models.
