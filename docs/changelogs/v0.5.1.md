# Changelog — Meow Gateway v0.5.0 → v0.5.1

## 🐛 Bug Fixes
- Anthropic Messages API: return the client-requested (virtual) model id in the
  response instead of the underlying provider model id. Claude Code validates
  the returned model against the requested one, so returning the provider id
  made it report "the selected model may not exist" even though the request
  succeeded.

## 🧹 Internal & Docs
- Bump workspace packages and gateway default version to 0.5.1.
