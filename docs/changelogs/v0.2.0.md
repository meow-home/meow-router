# Changelog — Meow Gateway v0.1.0 → v0.2.0

## 🚀 New Features

### Usage dashboard
- Show the provider display name in the "By provider" table instead of bare ids.
- Paginate the recent-requests list instead of loading a fixed batch.
- Surface the error message for failed requests in a dedicated column.
- Add a manual Reload button to refresh totals and the current page on demand.

### Virtual models
- Move "New Virtual Model" into a modal with a provider dropdown and a
  provider-model picker (no more free-typed model ids).
- Add "Edit" support to virtual models, pre-filled from the existing record.
- Require confirmation before deleting a virtual model.

### Providers & models
- Move the Add/Edit model form into a modal for a consistent, focused flow.
- Require confirmation before deleting providers and models.
- Render model status (enabled/disabled/stale) as colored badges instead of
  plain text.

### Application polish
- Sidebar footer shows the gateway running state (up/down) and the app version
  (via a new `app:get-version` IPC channel).

## 🐛 Bug Fixes
- Gateway: `stop()` now clears the server listener so the status correctly
  reports "down" after shutdown, and the instance can be restarted.
- UI: a controlled `Select` no longer receives both `value` and `defaultValue`
  (fixed the React "controlled/uncontrolled" warning).

## 🧹 Internal & Docs
- Add `request_usage.error_message` migration (v7) and update the data model
  docs.
- Update tests and test fixtures for the new usage, modal and status changes.
- Bump version to 0.2.0.
