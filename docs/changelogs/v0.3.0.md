# Changelog — Meow Gateway v0.2.0 → v0.3.0

## 🚀 New Features
- Keep each page's header fixed at the top of the content area while the rest
  of the page scrolls beneath it (sticky header with a frosted backdrop).

## 🐛 Bug Fixes
- Release pipeline: re-running a release on an existing tag no longer fails
  with `ReleaseAsset.name already exists` or `release not found`. The workflow
  now reuses the existing release and overwrites its assets (`--clobber`) when
  the tag is re-published.
- Release pipeline: internal Electron/Chromium binaries (e.g.
  `chrome_crashpad_handler` and any `*.pak`/`*.dll`/`*.bin` inside
  `*-unpacked/`) are no longer uploaded as release assets — only the real
  distribution artifacts are published.

## 🧹 Internal & Docs
- Update gateway default version and API doc to 0.3.0.
- Bump all workspace packages to 0.3.0.
