# Changelog — Meow Gateway v0.4.0 → v0.5.0

## 🚀 New Features

### Anthropic Messages API (`POST /v1/messages`)
- Add an Anthropic Messages compatibility endpoint so Anthropic-native clients
  (e.g. Claude Code) can talk to the gateway. The gateway translates the
  Anthropic wire format to its provider-neutral contract, dispatches through the
  same routing/fallback machinery as chat completions, then serializes the
  response back into Anthropic Messages JSON or SSE
  (`message_start`/`content_block_*`/`message_delta`/`message_stop`).
- Supports streaming and non-streaming, system prompts, tool definitions,
  tool_choice, tool_result/tool_use message blocks, and usage tracking.

### Self-contained landing page
- Add a self-contained Meow Gateway landing page for GitHub Pages that
  describe the loopback-infrastructure concept and how it works.

## 🐛 Bug Fixes
- Provider: when a provider closes the TCP socket mid-stream (a FIN before the
  `[DONE]` SSE terminator), the gateway now surfaces a retryable
  `PROVIDER_UNAVAILABLE` error instead of a raw `TypeError` that client SDKs
  wrapped as `AI_APICallError`. This lets the gateway retry / fall back instead
  of failing the request.

## 🧹 Internal & Docs
- Update gateway default version and API doc to 0.5.0.
- Bump all workspace packages to 0.5.0.
- Make the landing page header sticky with a blurred backdrop, and rework the
  design around the loopback-infrastructure concept.
- Add a GitHub Pages deploy workflow for the docs site and publish only the
  real distribution artifacts.
