One local endpoint for every AI agent

Problem → Solution

Every agent used to need its own config.

The problem

Each coding agent wants its own provider settings, model names, API keys — and sometimes an incompatible API format. Switching models is tedious and you have no visibility into tokens or cost.

The solution

One local endpoint. Configure providers once, then point every agent at the same place. Meow Gateway handles authentication, model selection, protocol translation, routing, streaming, retries and usage tracking.

http://127.0.0.1:8317/v1

What you get

Infrastructure your agents can share.

Provider management

Connect any provider

Add, remove, enable and disable providers. Validate credentials, test connectivity, and set a custom endpoint where the provider allows it.

Secure credentials

Keys stay local

Credentials live in the operating system credential store — os keychain / deep store — never in renderer state or plaintext.

Virtual models

Stable model IDs

Map cumbersome provider model IDs to friendly, stable virtual model IDs. Swap the underlying model without touching your agent config.

OpenAI-compatible API

Drop-in endpoint

Providers /v1/models and /v1/chat/completions with SSE streaming, served on localhost.

Observability

See the spend

Track request count, input/output tokens, cached tokens, latency, and estimated cost so you know exactly what each agent is using.

Routing & fallback

Resilient by default

Configure primary and fallback providers, retry policies, and model groups for capability-aware routing.

Request path

How a request travels.

01
Agent

Your coding agent

Makes an OpenAI-compatible call to the local endpoint.

02
Meow Gateway

The gateway

Resolves the virtual model, authenticates, translates the protocol, routes, streams and retries.

← response streamed back
03
Provider

Cloud provider

Runs the model; the reply streams back through the gateway to your agent.

Point your agent at http://127.0.0.1:8317/v1 and give it the gateway API key — no per-agent provider config.
